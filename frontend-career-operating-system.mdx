# Frontend Career Operating System

> **Learn → Build → Ship → Show → Sell → Deliver → Learn from reality**

This is not another giant roadmap.

It is a **career operating system** for a frontend developer with ~2 years of experience who wants to:

- become technically stronger
- switch to a better frontend job
- build a serious portfolio
- start earning through freelance work
- build a professional online presence
- gain real-world project and delivery experience

---

## The 4 Engines

Your career runs on four connected engines.

| Engine | Purpose | Main Output |
| --- | --- | --- |
| 🧠 **Skill** | Become a stronger developer | Technical ability |
| 🏗️ **Project** | Prove you can build | Flagship projects + experiments |
| 📣 **Content** | Make your work visible | Public proof + reputation |
| 💰 **Freelance** | Turn ability into money | Clients + delivery experience |

These engines reinforce each other.
